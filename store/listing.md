## Description

Scrollback keeps a copy of the Discord messages you open, so you can search them, export them and keep them.

It works by reading the message lists your Discord tab already downloads. It sends no requests to Discord of its own and never touches your login token. Everything stays in your browser.

WHAT YOU CAN DO
• Copy a whole chat to the clipboard in one click, ready to paste into notes or an AI assistant
• Download as Text, Markdown, HTML (with inline images), JSON or CSV
• Load the last 7, 30 or 90 days, or the full history, with one button. Scrollback scrolls the chat for you and shows progress on the page
• Remembers what it already saved, so repeat exports are instant and only new messages get loaded
• Export every text channel in a server at once
• Keep replies, edits, embeds, stickers, reactions and who reacted
• Save the images and videos from a chat into a tidy Downloads folder
• Browse and search every saved chat in the library page
• Back up all saved chats to one JSON file and restore them on another computer

PRIVATE BY DESIGN
• No account, no server, no analytics, no remote code
• No login token, cookies or headers are read
• Data lives in your browser profile until you delete it

GOOD TO KNOW
• Works on discord.com, ptb.discord.com and canary.discord.com in the browser. It does not work in the Discord desktop app
• Discord attachment links expire after about a day, so save media soon after loading a chat
• Only export chats you have the right to keep. Respect the people in them and Discord's Terms of Service

Scrollback is not affiliated with or endorsed by Discord Inc.

## Single purpose (Privacy practices tab)

Scrollback saves Discord messages that the user opens in their own browser and lets the user export them as files or copy them.

## Permission justifications

storage: Saves user settings and a flag that records the one-time upgrade from the previous storage format.

unlimitedStorage: Saved chats can hold hundreds of thousands of messages. Without this, the browser would evict the user's archive when the default quota is reached.

downloads: Writes export files and, only when the user clicks "Save media", the images and videos from a chat into the user's Downloads folder.

Host permission (discord.com, ptb.discord.com, canary.discord.com): The content scripts read the message lists the Discord web app downloads and show job progress on the page. The extension runs on no other site.

Remote code: No. All code ships in the package. No eval, no remote scripts.
